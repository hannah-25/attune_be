# 작업/변경 요약 템플릿

작은 작업이나 PR 설명에 쓰는 경량 템플릿. (큰 작업은 [exec-plans/template.md](../exec-plans/template.md))

```markdown
## 무엇을 / 왜

- 작업 한 줄 요약과 배경(이슈/요구).

## 변경 내용

- 핵심 변경 파일·동작.

## 영향 범위

- 영향받는 모듈/엔드포인트/데이터.
- 비호환 변경 여부 (있으면 명시 + 사람 확인 여부).

## 테스트

- 추가/수정한 테스트와 실행 결과(`scripts/agent/verify` 통과 여부).

## 문서

- 갱신한 문서 목록 (doc-gardening 매핑 기준).

## 체크리스트

- [ ] verify 통과  - [ ] 테스트 추가  - [ ] 문서 갱신  - [ ] secret 미커밋
```
